# Dra. Lilian Guimarães — Estética

Site institucional desenvolvido para Dra. Lilian Guimarães, Farmacêutica Esteta.

## ✨ Sobre o projeto

Website profissional com foco em estética facial e corporal, apresentando a profissional, procedimentos, resultados e formas de contato.

## 🛠️ Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## 📱 Responsividade

O projeto foi desenvolvido para funcionar em:

- Desktop
- Tablet
- Smartphone
